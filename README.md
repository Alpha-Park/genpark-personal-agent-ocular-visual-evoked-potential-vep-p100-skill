# Ocular Pattern-Reversal Visual Evoked Potential (PR-VEP) & P100 Latency Skill

A production-grade, zero-mock personal agent skill engineered for neuro-ophthalmological visual pathway evaluation, retinocortical conduction velocity profiling, and optic neuropathy assessment.

## Features
- **P100 Latency & Dispersion Quantification**: Detects subclinical and overt anterior pathway demyelination.
- **Axonal Amplitude Tracking**: Measures N75-P100 peak-to-peak voltage for axonal drop-out detection.
- **Interocular Symmetry Auditing**: Highlights unilateral conduction discrepancies.
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.
